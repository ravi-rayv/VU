# Original notebooks of the paper

These are the three notebooks used for the Bengaluru study, with personal paths replaced by placeholders and outputs cleared. They are kept for transparency and reproducibility. For new analyses, use the `vertical25d` package, the portal or the command-line tool, which implement the same method (with the small fixes listed in the main README).

1. `Building_Height_Viz.ipynb`: OSM buildings, Earth Engine heights, floor calibration, change 2016–2023, figures V1–V7.
2. `POI_to_Buildings.ipynb`: POI classification, floor extraction, linking to buildings, figures P1–P5.
3. `Vertical_Entropy.ipynb`: floor-band prediction, Monte Carlo indices, ward statistics, figures E1–E7.
